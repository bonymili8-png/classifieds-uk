# E2E-тести (Playwright) — опційні

Ці тести **не потрібні** для роботи застосунку і навмисно винесені в окрему
теку з власними залежностями, щоб основний проєкт лишався без npm-залежностей.

## Запуск

```bash
cd e2e
npm install
npm run install-browsers   # завантажує Chromium
npm test
```

Playwright сам підніме застосунок (`node ../server.js` на порту 3099) на час
тестів і зупинить його після.

## Що покривають

- головна: категорії та стрічка свіжих оголошень;
- пошук із фільтрацією;
- сторінка оголошення (контакти, опис);
- перемикання мови UA/EN;
- повний сценарій: реєстрація → створення оголошення з характеристиками →
  позначення проданим;
- збереження в обране.

Юніт/інтеграційні тести API (без залежностей) лишаються в `../test` і
запускаються через `node --test`.
