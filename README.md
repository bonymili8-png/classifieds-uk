# ОголошенняUK 🇺🇦🇬🇧

Сучасний, швидкий та адаптивний веб/мобільний застосунок (PWA) **дошки оголошень для українців у Великій Британії**.

Короткі універсальні оголошення: **ціна**, **фото** (показуються лише на сторінці самого оголошення), **телефон / WhatsApp / Telegram**, **коротка назва + опис**, **місто або пост-код** (повний чи частковий).

## Можливості

- 📱 **Адаптивний дизайн** — однаково зручно на телефоні й на десктопі (нижня таб-навігація на мобільних).
- ⚡ **Швидкий** — без важких фреймворків. Сервер на чистому Node.js, фронтенд — ванільні ES-модулі.
- 🌐 **Двомовність UA / EN** — перемикання однією кнопкою, мова запам'ятовується.
- 👤 **Акаунти користувачів** — реєстрація, вхід, профіль з аватаром, публічна сторінка продавця. Паролі хешуються (scrypt + сіль), сесії на токенах.
- 💬 **Внутрішній чат** — листування між покупцем і продавцем прямо на сайті, лічильник непрочитаних, діалоги, прив'язані до оголошення.
- 🗂️ **16 категорій** — робота, житло, послуги, транспорт, речі, меблі, електроніка, дитячі товари, краса, документи, навчання, тварини, їжа, безкоштовно, спільнота, інше.
- 🧩 **Характеристики за категоріями** — динамічні поля: для «Житло» — кімнати/меблювання/рахунки/період; «Робота» — зайнятість/графік/оплата; «Транспорт» — марка/рік/пробіг/паливо; «Електроніка/Меблі/Речі» — стан тощо. Показуються на картці й сторінці, доступні для фільтрації.
- 🔍 **Пошук і фільтри** — за словом, містом/індексом, ціною, характеристиками, лише безкоштовні, лише з фото, сортування.
- 🖼️ **Фото** — до 8 на оголошення, стискаються в браузері; у стрічці **не показуються**, тільки на сторінці оголошення (як у вимозі). Перегляд у лайтбоксі.
- 🏷️ **Статуси оголошень** — активне / продано, а також «підняти» оголошення нагору.
- ☎️ **Контакти в один тап** — подзвонити, написати у WhatsApp, Telegram або в чаті сайту.
- ⚑ **Скарги / модерація** — користувачі можуть поскаржитися на оголошення.
- 🛡️ **Адмін-панель** — статистика, перегляд і закриття скарг, видалення будь-якого оголошення.
- 🔔 **Сповіщення** про нові повідомлення (локальні, поки вкладка відкрита).
- ⭐ **Рейтинги та відгуки продавців** — оцінка 1–5 зірок із коментарем, агрегований рейтинг у профілі та на картці продавця.
- 🔑 **Відновлення пароля** — одноразові токени з терміном дії 30 хв (у демо-режимі токен показується в інтерфейсі).
- 📝 **Автозбереження чернетки** оголошення — форма не втрачається при випадковому закритті.
- 🔒 **Безпека** — rate-limiting (антибрутфорс/антиспам), заголовки безпеки (CSP, X-Frame-Options, nosniff тощо).
- 🔎 **SEO** — `robots.txt` і динамічний `sitemap.xml` з активними оголошеннями.
- 💾 **Бекап даних** — адмін може завантажити повний дамп бази (без паролів і токенів).
- 🐳 **Розгортання** — Dockerfile + docker-compose з томами для даних і фото.
- 🧪 **Автотести** — інтеграційний набір на `node:test` (53 перевірки) + CI на GitHub Actions.
- ⭐ **Збережені** та 👤 **Мої оголошення** (для гостей — за токеном пристрою; для зареєстрованих — у профілі).
- 🌙 **Світла / темна тема**, 📦 **офлайн-режим** і встановлення як застосунку (PWA).

## Запуск

Потрібен лише Node.js 18+ (жодних залежностей встановлювати не треба):

```bash
npm start
# або
node server.js
```

Відкрийте <http://localhost:3000>.

Змінні оточення:
- `PORT` — порт (типово 3000)
- `HOST` — хост (типово 0.0.0.0)
- `SITE_URL` — публічна адреса (для канонічних URL у `sitemap.xml`), напр. `https://your-domain`
- `ADMIN_EMAILS` — email-и адміністраторів через кому. Якщо не задано, адміном
  автоматично стає **перший зареєстрований** користувач (зручно для self-host).
- `EXPOSE_RESET_TOKEN=1` — у відповіді `/api/auth/forgot` повертати токен скидання
  пароля (для демо/self-host без email-сервера). У продакшені вимкнено.
- `DISABLE_RATE_LIMIT=1` — вимкнути обмеження частоти запитів (для тестів/розробки).

## Розгортання (Docker)

```bash
docker compose up -d --build
```

Дані бази та завантажені фото зберігаються у томах `ouk-data` та `ouk-uploads`,
тож переживають перезапуск. Налаштуйте `SITE_URL` і `ADMIN_EMAILS` у
`docker-compose.yml`. Або вручну:

```bash
docker build -t ogoloshennia-uk .
docker run -p 3000:3000 -v ouk-data:/app/data -v ouk-uploads:/app/public/uploads ogoloshennia-uk
```

## Тести

Автоматизовані інтеграційні тести API (вбудований `node:test`, без залежностей):

```bash
npm test        # або: node --test
```

Тести піднімають сервер у підпроцесі й перевіряють авторизацію, оголошення,
права доступу, чат, відгуки, скидання пароля, скарги, адмін-панель, бекап,
безпеку (заголовки, rate-limit), SEO (robots/sitemap) і статику
(53 перевірки). Ті самі тести виконуються в CI на Node 18/20/22.

## Структура

```

data/listings.json     демо-дані (seed) — копіюються у db.runtime.json при першому старті
test/api.test.js       інтеграційні тести API
.github/workflows/ci.yml  CI: запуск тестів на push/PR
Dockerfile, docker-compose.yml  розгортання
public/
  index.html           оболонка застосунку
  css/styles.css       стилі (теми, адаптив, чати, модалки, лайтбокс)
  js/app.js            роутер, тема, мова, сесія, події
  js/views.js          екрани (головна, пошук, деталі, форма, профіль, чати, авторизація…)
  js/api.js            клієнт API + сесія + localStorage
  js/data.js           категорії, міста, утиліти форматування
  js/i18n.js           словники UA/EN і функція t()
  js/attributes.js     підписи характеристик (UA/EN) для динамічних полів
  manifest.webmanifest, service-worker.js, icons/   PWA
scripts/gen-icons.mjs  генерація PNG-іконок без залежностей
```

## API (коротко)

**Оголошення**

| Метод  | Шлях                  | Опис                                  |
|--------|-----------------------|---------------------------------------|
| GET    | `/api/listings`       | список + фільтри (`q,category,city,min,max,free,photo,sort,page,owner,status,attr_*`) |
| GET    | `/api/meta/attributes`| схема характеристик за категоріями    |
| GET    | `/api/listings/:id`   | одне оголошення (рахує перегляди)     |
| POST   | `/api/listings`       | створити (гість → `editToken`; авторизований → прив'язка до акаунта) |
| PUT    | `/api/listings/:id`   | редагувати / `action:status` / `action:bump` |
| DELETE | `/api/listings/:id`   | видалити                              |

**Акаунти**

| Метод | Шлях                    | Опис                          |
|-------|-------------------------|-------------------------------|
| POST  | `/api/auth/register`    | реєстрація → `{token, user}`  |
| POST  | `/api/auth/login`       | вхід → `{token, user}`        |
| POST  | `/api/auth/logout`      | вихід                         |
| GET   | `/api/auth/me`          | поточний користувач           |
| PUT   | `/api/auth/me`          | оновити профіль (ім'я, місто, телефон, аватар) |
| POST  | `/api/auth/forgot`      | запит на скидання пароля (надсилає токен) |
| POST  | `/api/auth/reset`       | встановити новий пароль за токеном |
| GET   | `/api/users/:id`        | публічний профіль + статистика + рейтинг |

**Відгуки**

| Метод | Шлях                          | Опис                              |
|-------|-------------------------------|-----------------------------------|
| GET   | `/api/users/:id/reviews`      | список відгуків + агрегований рейтинг |
| POST  | `/api/users/:id/reviews`      | залишити/оновити відгук (1–5 + текст) |

**Чат і скарги**

| Метод | Шлях                       | Опис                              |
|-------|----------------------------|-----------------------------------|
| GET   | `/api/messages`            | список діалогів                   |
| GET   | `/api/messages/unread`     | кількість непрочитаних            |
| POST  | `/api/messages`            | почати діалог щодо оголошення     |
| GET   | `/api/messages/:threadId`  | повідомлення діалогу (познач. прочитаними) |
| POST  | `/api/messages/:threadId`  | відповісти                        |
| POST  | `/api/reports`             | поскаржитися на оголошення        |

**Адмін (лише для адміністратора)**

| Метод  | Шлях                            | Опис                            |
|--------|---------------------------------|---------------------------------|
| GET    | `/api/admin/stats`              | зведена статистика              |
| GET    | `/api/admin/reports`            | список скарг (`?resolved=1` — закриті) |
| POST   | `/api/admin/reports/:id`        | закрити/відкрити скаргу         |
| DELETE | `/api/admin/listings/:id`       | видалити будь-яке оголошення    |
| GET    | `/api/admin/backup`             | дамп бази (без паролів/токенів) |

**SEO** (поза `/api`): `GET /robots.txt`, `GET /sitemap.xml`.

Авторизація — заголовком `Authorization: Bearer <token>`. Фото/аватари надсилаються як
`data:`-URL; сервер зберігає їх у `public/uploads/`.

## Примітки

- Сховище — простий JSON-файл, чудово для прототипу / невеликого спільнотного сайту. Для масштабування варто замінити на БД (Postgres/SQLite).
- Право на редагування підтверджується токеном, який зберігається в `localStorage` пристрою.
