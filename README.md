# ОголошенняUK 🇺🇦🇬🇧

Сучасний, швидкий та адаптивний веб/мобільний застосунок (PWA) **дошки оголошень для українців у Великій Британії**.

Короткі універсальні оголошення: **ціна**, **фото** (показуються лише на сторінці самого оголошення), **телефон / WhatsApp / Telegram**, **коротка назва + опис**, **місто або пост-код** (повний чи частковий).

## Можливості

- 📱 **Адаптивний дизайн** — однаково зручно на телефоні й на десктопі (нижня таб-навігація на мобільних).
- ⚡ **Швидкий** — без важких фреймворків. Сервер на чистому Node.js, фронтенд — ванільні ES-модулі.
- 🌐 **Двомовність UA / EN** — перемикання однією кнопкою, мова запам'ятовується.
- 👤 **Акаунти користувачів** — реєстрація, вхід, профіль з аватаром, публічна сторінка продавця. Паролі хешуються (scrypt + сіль), сесії на токенах.
- 🔐 **Реєстрація-гейт** — контакти оголошення (телефон/WhatsApp/Telegram) видно лише після входу; додавання оголошення спонукає зареєструватися (з опцією «як гість»); кнопка **«Реєстрація»** у шапці.
- 💬 **Внутрішній чат** — листування між покупцем і продавцем прямо на сайті, лічильник непрочитаних, діалоги, прив'язані до оголошення.
- 🗂️ **16 категорій** — робота, житло, послуги, транспорт, речі, меблі, електроніка, дитячі товари, краса, документи, навчання, тварини, їжа, безкоштовно, спільнота, інше.
- 🧩 **Характеристики за категоріями** — динамічні поля: для «Житло» — кімнати/меблювання/рахунки/період; «Робота» — зайнятість/графік/оплата; «Транспорт» — марка/рік/пробіг/паливо; «Електроніка/Меблі/Речі» — стан тощо. Показуються на картці й сторінці, доступні для фільтрації.
- 🔍 **Пошук і фільтри** — за словом, містом/індексом, ціною, характеристиками, лише безкоштовні, лише з фото, сортування.
- 🖼️ **Фото** — до 8 на оголошення, стискаються в браузері; у стрічці **не показуються**, тільки на сторінці оголошення (як у вимозі). Перегляд у лайтбоксі.
- 🏷️ **Статуси оголошень** — активне / продано / прострочене / архів, а також «підняти» оголошення нагору.
- ⏳ **Термін дії та автозастарівання** — оголошення живе `LISTING_TTL_DAYS` днів (типово 45), потім автоматично стає `expired`, зникає з пошуку **та з індексації** (sitemap). Власник може продовжити («Продовжити»), редагування теж реактивує.
- 🔎 **SEO-сторінки оголошень** — справжні індексовані URL `/listing/:id` із серверним `<title>`, `meta description`, Open Graph і **JSON-LD** (Schema.org Product/Offer). Прострочені віддаються з `noindex`/`410`.
- ☎️ **Контакти в один тап** — подзвонити, написати у WhatsApp, Telegram або в чаті сайту.
- 💰 **Монетизація** — преміум-розміщення (виділені «ТОП», платне «підняти»), **PRO-підписки** (місяць/рік, вищий ліміт оголошень + **знижка −20% на просування**), **промокоди** (відсоток/фікс, ліміт використань, термін дії; 100% = безкоштовна активація). Усі тарифи й промокоди **редагуються в адмінці** (CRUD). Квота безкоштовних оголошень. **Stripe Checkout** (без SDK) з перевіркою підпису вебхука; сторінка **«Мої платежі»**. Демо-режим без ключів. Виділені завжди вище у видачі.
- 🎁 **Реферальна програма** — у кожного користувача персональне посилання; коли запрошений уперше оплачує, реферер отримує бонусні дні PRO. Лічильник запрошених у профілі.
- ✉️ **Email-нагадування про підписку** — автоматичний лист за кілька днів до завершення PRO (фоновий планувальник + ручний запуск з адмінки).
- 📊 **Аналітика** — трекінг подій (перегляди, кліки по контактах, чати, збереження); **статистика для власника** на сторінці оголошення; **адмін-дашборд** із 14-денним графіком переглядів/контактів/нових оголошень і показниками доходу.
- ⚑ **Скарги / модерація** — користувачі можуть поскаржитися на оголошення.
- 🛡️ **Адмін-панель управління** — вкладки «Огляд / Аналітика / Оголошення / Користувачі / Дохід / **Тарифи** / **Промокоди** / Скарги»: редагування будь-якого оголошення, **CRUD тарифів і промокодів**, управління користувачами (бан/розбан, адмін-права, **видача/зняття PRO**), журнал дій (audit log), доходи й замовлення, статистика, бекап.
- 🔔 **Сповіщення** про нові повідомлення (локальні, поки вкладка відкрита).
- 📧 **Email-листи** — вітання при реєстрації, скидання пароля, сповіщення про нові повідомлення в чаті. Власний SMTP-клієнт без залежностей (TLS/STARTTLS, AUTH LOGIN, кирилиця). Без SMTP — листи лише логуються.
- ⭐ **Рейтинги та відгуки продавців** — оцінка 1–5 зірок із коментарем, агрегований рейтинг у профілі та на картці продавця.
- 🔑 **Відновлення пароля** — одноразові токени з терміном дії 30 хв (у демо-режимі токен показується в інтерфейсі).
- 📝 **Автозбереження чернетки** оголошення — форма не втрачається при випадковому закритті.
- 🔒 **Безпека** — rate-limiting (антибрутфорс/антиспам), заголовки безпеки (CSP, X-Frame-Options, nosniff тощо).
- 🔎 **SEO** — `robots.txt` і динамічний `sitemap.xml` з активними оголошеннями.
- 💾 **Бекап даних** — адмін може завантажити повний дамп бази (без паролів і токенів).
- 🐳 **Розгортання** — Dockerfile + docker-compose з томами для даних і фото.
- 🧪 **Автотести** — інтеграційний набір на `node:test` (106 перевірок) + CI на GitHub Actions.
- ⭐ **Збережені** та 👤 **Мої оголошення** (для гостей — за токеном пристрою; для зареєстрованих — у профілі).
- 🌙 **Світла / темна тема**, 📦 **офлайн-режим** і встановлення як застосунку (PWA).

## Запуск

Потрібен лише Node.js 18+ (жодних залежностей встановлювати не треба):

```bash
npm start
# або
node server.js
```

Відкрийте <http://localhost:3000>.

Змінні оточення:
- `PORT` — порт (типово 3000)
- `HOST` — хост (типово 0.0.0.0)
- `SITE_URL` — публічна адреса (для канонічних URL у `sitemap.xml`), напр. `https://your-domain`
- `ADMIN_EMAILS` — email-и адміністраторів через кому. Якщо не задано, адміном
  автоматично стає **перший зареєстрований** користувач (зручно для self-host).
- `EXPOSE_RESET_TOKEN=1` — у відповіді `/api/auth/forgot` повертати токен скидання
  пароля (для демо/self-host без email-сервера). У продакшені вимкнено.
- `DISABLE_RATE_LIMIT=1` — вимкнути обмеження частоти запитів (для тестів/розробки).
- `LISTING_TTL_DAYS` — термін дії оголошення в днях до автозастарівання (типово 45).
- `FREE_LISTING_QUOTA` — скільки активних оголошень безкоштовно на акаунт (типово 10).
- `PRO_LISTING_QUOTA` — ліміт активних оголошень для PRO-передплатників (типово 100).
- `PRO_PROMO_DISCOUNT` — знижка PRO на просування оголошень, % (типово 20).
- `REFERRAL_BONUS_DAYS` — скільки днів PRO нараховувати рефереру за першу оплату запрошеного (типово 30).
- `SUB_REMINDER_DAYS` — за скільки днів до завершення PRO надсилати нагадування (типово 3).
- `PAYMENTS_AUTO_CONFIRM=1` — демо-режим без Stripe: власник підтверджує оплату сам. З увімкненим Stripe ігнорується (оплати приходять вебхуком).
- `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` — справжні платежі через Stripe Checkout. Без них працює демо-режим. Налаштування: див. нижче.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_SECURE`, `MAIL_FROM` —
  надсилання листів (вітання, скидання пароля, нові повідомлення). Без `SMTP_HOST`
  листи лише логуються — застосунок працює як завжди.

### Платежі (Stripe)

Інтеграція без SDK (на вбудованих модулях). Щоб увімкнути справжні оплати:

1. Створіть ключ у Stripe Dashboard → `STRIPE_SECRET_KEY=sk_live_...` (або `sk_test_...`).
2. Додайте webhook-ендпоінт `https://ваш-домен/api/stripe/webhook`, подія
   `checkout.session.completed` → скопіюйте `STRIPE_WEBHOOK_SECRET=whsec_...`.
3. Перезапустіть застосунок. Тепер «🚀 Просувати» веде на захищену сторінку
   Stripe Checkout; після оплати webhook автоматично активує преміум.

Без цих змінних застосунок працює в демо-режимі (підтвердження вручну),
жодних зовнішніх викликів не робиться.

### Швидкість і безпека

- **Gzip-стиснення** API-відповідей і HTML; `modulepreload`/`preload` критичних ресурсів; офлайн-кеш (Service Worker) → швидке завантаження.
- **Захист:** rate-limiting (антибрутфорс на вхід/реєстрацію/скидання, антиспам на оголошення/чат), CSP із nonce, HSTS за HTTPS, `X-Frame-Options`, `X-Content-Type-Options`, захист від path-traversal, паролі scrypt+сіль, токени не витікають у бекап/API.
- **SEO:** індексовані `/listing/:id`, `robots.txt`, `sitemap.xml` (лише живі оголошення), JSON-LD, канонічні URL, Open Graph.

## Розгортання

Готові конфіги HTTPS (nginx + certbot, Caddy), systemd-юніт та покрокова
інструкція — у [`deploy/`](deploy/README.md).

### Docker

```bash
docker compose up -d --build
```

Дані бази та завантажені фото зберігаються у томах `ouk-data` та `ouk-uploads`,
тож переживають перезапуск. Налаштуйте `SITE_URL` і `ADMIN_EMAILS` у
`docker-compose.yml`. Або вручну:

```bash
docker build -t ogoloshennia-uk .
docker run -p 3000:3000 -v ouk-data:/app/data -v ouk-uploads:/app/public/uploads ogoloshennia-uk
```

## Тести

Автоматизовані інтеграційні тести API (вбудований `node:test`, без залежностей):

```bash
npm test        # або: node --test
```

Тести піднімають сервер у підпроцесі й перевіряють авторизацію, оголошення,
права доступу, чат, відгуки, скидання пароля, скарги, адмін-панель, бекап,
безпеку (заголовки, rate-limit), SEO (robots/sitemap) і статику
(106 перевірок). Ті самі тести виконуються в CI на Node 18/20/22.

## API (коротко)

**Оголошення**

| Метод  | Шлях                  | Опис                                  |
|--------|-----------------------|---------------------------------------|
| GET    | `/api/listings`       | список + фільтри (`q,category,city,min,max,free,photo,sort,page,owner,status,attr_*`) |

| GET    | `/api/listings/:id`   | одне оголошення (рахує перегляди)     |

| DELETE | `/api/listings/:id`   | видалити                              |
| GET    | `/listing/:id`        | **SEO-сторінка** (HTML з метатегами, OG, JSON-LD) |

| GET    | `/api/admin/backup`             | дамп бази (без паролів/токенів) |

**SEO** (поза `/api`): `GET /robots.txt`, `GET /sitemap.xml`, `GET /listing/:id`.

Авторизація — заголовком `Authorization: Bearer <token>`. Фото/аватари надсилаються як
`data:`-URL; сервер зберігає їх у `public/uploads/`.

## Примітки

- Сховище — простий JSON-файл, чудово для прототипу / невеликого спільнотного сайту. Для масштабування варто замінити на БД (Postgres/SQLite).
- Право на редагування підтверджується токеном, який зберігається в `localStorage` пристрою.
